# Security reporting

For sensitive vulnerability reports, contact the repository owner privately through an established channel. Do not include production logs, credentials or personal data in public issues. Non-sensitive reproducible bugs can be filed as repository issues.

AuthTrail processes untrusted log content offline. Keep Python patched and run as an unprivileged user. Raw evidence is included in reports and may contain sensitive values. Only Linux and Python 3.10–3.14 are currently validated; Windows and macOS are not claimed as supported deployment targets.
